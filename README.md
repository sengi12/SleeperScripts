# SleeperScripts
Fantasy Football related python scripts that utilize the sleeper API to accumulate interesting statistics

## Scripts

- `get_weekly_high_scores.py` — walks a league week by week, names the top scorer each week (and the runner-up with the margin), then tallies the season: weeks as the top scorer per team, with the weeks and total points. `-id` league, `-w` through a week, `--playoffs`, `--all-seasons`.
